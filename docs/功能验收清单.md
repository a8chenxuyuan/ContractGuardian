## 七、已知限制

| 项 | 说明 |
|---|---|
| WeasyPrint 缺 GTK | 本机 Windows 无 GTK 运行库，PDF 走 xhtml2pdf 降级链（已实测中文正常）；Linux 生产环境优先 WeasyPrint |
| REVIEW_SOFT_TIME_LIMIT | Celery 软超时仅 Linux 生效，Windows 开发环境不生效 |
| AUTO_CREATE_TABLES | create_all 只建新表不加新列，**新增列需手动 ALTER TABLE**（Alembic 迁移列入后续 P2 计划） |
| 图片合同 | OCR 依赖视觉模型配额；PDF 无文本层不支持划词追问 |
