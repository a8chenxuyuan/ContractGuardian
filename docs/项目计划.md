# 合同卫士 — 项目实施计划（完整版）

## 一、项目概述

**项目名称**：合同卫士（ContractGuard）

**项目定位**：
面向个人与中小企业的专业级 AI 合同审查助手。用户上传合同后，系统自动识别风险条款、解释法律含义、给出修改建议，并支持原文高亮与多格式报告导出。系统以劳动合同审查为核心场景，已扩展支持租房合同、买卖合同、借款合同、技术服务合同、股权转让等高频合同类型。

**核心差异点**：
- 结构化风险审查 + 原文高亮 + 可执行修改建议
- 多 Agent 并行审查，结论可追溯、可验证
- 法律知识库驱动，引用真实法规与案例
- 支持人机协同复核，低置信度项目转人工
- 审查经验持续沉淀，系统越用越准

## 六、关键技术决策

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 后端框架 | FastAPI（Python） | 开发快、Agent 生态成熟 |
| 数据库 | PostgreSQL | 关系型数据稳定，支持 JSONB 存储结构化审查结果 |
| 缓存/队列 | Redis | 任务队列、分布式锁、缓存一体化 |
| 向量数据库 | Qdrant | 支持合同内语义搜索和法律知识库检索，可扩展 |
| 图数据库 | Neo4j | 构建法规-条款-案例知识图谱，支持跨实体关系查询 |
| 文档解析 | python-docx + PyMuPDF + PaddleOCR | 覆盖 Word/PDF/图片，开源可控 |
| LLM | 通义千问 / DeepSeek | 国内模型优先，成本低 |
| Embedding | BGE-M3 | 中文效果好，支持本地部署 |
| 前端 | Vue3 + TypeScript | 与现有项目技术栈一致 |
| Agent 框架 | 自定义 Coordinator + 自定义 ReAct | 状态管理 + 灵活工具调用 |
| 部署 | Docker + Kubernetes + 云服务 | 便于扩展和私有化部署 |

## 七、风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| LLM 输出不稳定 | 审查质量波动 | 强 Prompt 约束 + Pydantic 校验 + 多 Agent 交叉验证 |
| 法律建议错误 | 用户损失、法律风险 | 明确免责声明 + 关键问题引导人工律师 + LegalVerifyAgent |
| 用户隐私顾虑 | 不敢上传合同 | 数据加密 + 承诺不滥用 + 提供本地化处理选项 |
| 竞品竞争 | 通用 AI 工具也做合同审查 | 垂直场景 + 结构化输出 + 原文高亮 + 人工复核 |
| 知识库建设慢 | 审查效果依赖法规案例 | 本地知识库 + 联网搜索双层架构 + Knowledge Curator 自动沉淀 |
| 系统复杂度高 | 开发周期不可控 | 模块化设计 + 清晰接口 + 持续集成 |
